## Data and Figure Reproduction
To ensure full transparency and reproducibility:
1. **Raw/Processed Data**: All numerical data underlying the plots in the manuscript are organized and provided as `.csv` files in the `data/` directory.
2. **Figure Plotting**: The final figures were generated using **Origin** (OriginLab). Rather than providing plotting code, we have provided the exact `.csv` data tables. Readers can directly import these `.csv` files into Origin or any other plotting software (e.g., Python/Matplotlib) to reproduce the exact figures.

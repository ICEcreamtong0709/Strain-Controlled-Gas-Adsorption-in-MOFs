## Data and Figure Reproduction
To ensure full transparency and reproducibility:
1. **Data Tables**: All numerical data underlying the plots in the manuscript are provided as `.xlsx` files in the `data/` directory. 
2. **Figure Plotting**: The final figures were generated using **Origin** (OriginLab). Instead of plotting code, we provide the exact Excel data tables.  Readers can directly import these `.xlsx` files into Origin or any other plotting software to reproduce the exact figures.
